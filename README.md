# Szia! Üdv a profilomon! 👋

### 🚀 Egyetemi hallgató | Tech & DIY rajongó | Live Event Tech

Szenvedélyem a technológia minden formája – a kódsoroktól kezdve egészen a koncerttermek keverőpultjáig. Jelenleg az egyetemi tanulmányaim mellett leginkább blokklánc technológiával és hardveres DIY projektekkel foglalkozom.

---

### 🛠️ Amin éppen dolgozom:
* **Solana Bot:** Egyedi fejlesztésű kereskedő vagy elemző bot Solana hálózatra.
* **Smart Home / DIY:** ESP32 alapú otthoni kaputelefon-rendszer és egyéb okosmegoldások.
* **Live Production:** Rendezvények hang- és fénytechnikai kivitelezése (mixing, lighting cues).
