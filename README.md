### 🚀 Rólam röviden

Gyerekkorom óta a gyakorlati problémamegoldás és a technológia hajt. Hét évig foglalkoztam hang- és fénytechnikával, élő adásközvetítéssel (broadcast/streaming) és hardveres hibaelhárítással, miközben folyamatosan a szoftverfejlesztés felé tereltem a hangsúlyt. 

Jelenleg egyetemi tanulmányaimat folytatom (a cél a mesterképzés és a professzionális mérnöki karrier), miközben valós idejű adatelemző eszközöket, algoritmikus kereskedési botokat és megbízható backend architektúrákat fejlesztek.

* 🔭 **Jelenleg fókuszban:** Nagy megbízhatóságú kereskedési motorok, kockázatkezelési algoritmusok és API integrációk.
* 🎓 **Tanulmányok:** Mérnök-informatika (BSc -> MSc céllal).
* ⚙️ **Filozófia:** Strukturált, tiszta kód, minimalista függőségek és zéró kompromisszum a rendszerstabilitásban.
* ☕ **Érdeklődési körök:** Algoritmikus piacok, beágyazott rendszerek, audió jelfeldolgozás (DSP), hálózati protokollok.
